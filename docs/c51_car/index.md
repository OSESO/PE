# Task
Make an automatic line-following obstacle avoidance car. Folling the black line. The projection of the vehicle cannot be larger than the A4 paper. You need to reach the finish line as fast as you can.

# Request

1. It requires the use of 3S batteries to supply energy to the micro-processor and motor along with the designed power module.(20 points)

    1. The batteries and DC-DC core will provide by studio.

    2. It requires you design a PCB to connect the batteries and separate the power you need.

    3. The PCB design is beautiful, neat, and correctly displays the log of the college and "one student one chip".

    4. It is more intuitive to display the working status of the power board.

2. It requires to use two L298N to driving the motor(20 points)

    1. Each motor can be drived independently.

    2. It requires to control each motor`s speed, the speed needs to be converted to meters per second.

    3. It requires to change the speed by switch or key, and the speed needs to be displayed on 0.96 OLED.

3. It requires to design C51 PCB by yourself.(20 points)

    1. It requires capacitance and resistance`s footprint is 0603

    2. It requires C51`s footprint is LQFP

    3. It requires display logo of college and "one student one chip"

4. It requires the car can complete the track(20 points)

    1. If the car out of the track, 5 points will be deducted each time(Up to 20 points).

    2. If the car cann`t avoid obstacles, 10 points will be deducted.

    3. Additional, if less than the established time to complete, 5 points will be added each second.

5. It requires a design report(20 points)

    1. Comparison and selection of solutions

    2. Theoretical analysis and calculation

    3. Circuits and programming 

    4. Analysis of test results
